# Code of Conduct

Leverage adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project and
in every project space: issues, pull requests, discussions, and any other
channel the project uses.

## In short

- Be respectful and considerate. Assume good intent; critique ideas, not
  people.
- Harassment, discrimination, personal attacks, and publishing someone else's
  private information are not acceptable.
- Maintainers may remove, edit, or reject contributions and comments that
  violate the code of conduct, and may restrict the participation of people
  who do.

The full text at the link above is the authoritative version.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
project maintainer, [@yuric](https://github.com/yuric), using the contact
details on their GitHub profile. Reports are handled confidentially.
