Sample data. The grey bar is not part of the design. Click the lit control to move on; the task runs by itself on a timer once two agents are connected. Esc is the same as “Not now”.

What is new here

  • A “Get your first task done” card at the top of the board, shown until setup is finished or hidden. Its four steps tick from what is true in the workspace, not from what was clicked, so it survives a quit, a browser sign-in and a tool install.
  • The spotlight: the window dims and one control stays lit, with one sentence saying why. Only the lit control can be clicked. “Not now” ends it; “Show me” on the card brings it back.
  • Setup progress in the side pane, above the health line, on every tab.
  • In Add credential, a line that asks for a different provider the second time, and a hint beside each provider.
  • Connect agent opens with the next login that has no agent already picked.
  • The “first task” step lights Add task. When the gallery of ready-made tasks is in the app, it lights that too.
  • “Hide this” on the card ends setup at any point.

How to read it

  • This is what the owner gets after leaving the setup assistant (setup-assistant.html) with “Set up later” or “Skip, take me to the task board”.
  • The requirements are in docs/onboarding/PRD.md. Where this mockup and that document differ, the document is right.
  • The logins, agents, task and names are sample data. Screens that setup does not touch (Decided for you, Settings) are placeholders.
